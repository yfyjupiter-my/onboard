A · Editorial — Fraunces + Inter
B · One family — Inter only
C · Product — Space Grotesk + IBM Plex Sans

Sets differ only in the CSS variables at the top of each .set-* block — family, weight, size, tracking, line-height, label casing. Markup and colour are identical, so what you see is the type doing the work.

A · Teal titles — today's pairing, enlarged and tightened to -.02em; headings take --primary, labels take --accent. Flat, token-only, fully inside DESIGN.md.
B · Two-tone — Inter only (one fewer font file); colour used as emphasis, one word of each title in teal. Safest contrast-wise.
C · Gradient text — Space Grotesk + IBM Plex Sans with a teal→amber gradient title and score. Note: DESIGN.md §1 says "no gradients" and §2 calls Fraunces the warmth signal — picking C means amending both.

Contrast: teal #0f766e on white is 5.2:1 (passes AA at any size). Amber #d97706 is 3.1:1 — fine for the 11px bold uppercase labels as used here, but don't move it onto body text. Gradient text in C can't be contrast-checked automatically; it stays above 3:1 across the sweep at 30px.

Shipping note: the app loads no CDN fonts (COM-003 — privacy + offline). Choosing B needs no new file; A needs none either. C needs two woff2 files vendored into web/static/fonts/.
