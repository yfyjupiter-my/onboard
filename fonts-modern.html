D · Cut Serif — Instrument Serif + DM Sans

High-contrast display serif at 54px with a real italic for the coloured word. The amber hairline under the login title is the only ornament. Warmest of the three; closest in spirit to today's Fraunces.

E · Optical Grotesque — Bricolage Grotesque + Inter

Variable grotesque set at opsz 72, weight 800, tracking −.04em; the accent line drops to weight 500 in teal. Amber baseline highlight on card headlines. The most "designed" option — distinctly not a default sans.

F · Geometric + Mono — Outfit + Work Sans + JetBrains Mono

Geometric titles, humanist body, and monospace for every label, tag and numeral (kickers prefixed //). The mono carries the modern signal without touching reading text. Coolest of the three.

All three render identical markup and identical colour tokens — only the type variables at the top of each .set-* block differ. Colour on type stays inside DESIGN.md: titles/scores --primary, labels --accent, body always --text. No gradient text (§1 prohibits gradients); set E's highlight is a background wash behind the word, not gradient-filled glyphs.

Contrast: teal #0f766e on white 5.2:1 (AA all sizes). Amber #d97706 3.1:1 — used only on 11px bold uppercase labels and on large numerals, never body text. Status tags pair colour with an SVG icon, so colour is never the only signal.

Shipping cost: D = 2 woff2 · E = 2 woff2 (Bricolage is variable, one file covers 500–800) · F = 3 woff2. Each vendored into web/static/fonts/ with font-display:swap; picking any of these means amending DESIGN.md §2 since Fraunces stops being the warmth signal.
